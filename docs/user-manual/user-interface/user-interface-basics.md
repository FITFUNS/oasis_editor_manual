---
title: 사용자 인터페이스 기초 (User Interface Basics)
---

OasisW에서 사용자 인터페이스는 두 가지 부품으로 이루어집니다. [화면 컴포넌트][1]는 모든 인터페이스 요소가 놓이는 영역을 정하고, 그 아래에 [요소 컴포넌트][2]를 가진 여러 엔티티가 계층 구조상 화면 엔티티의 자식으로 붙습니다. 화면은 인터페이스가 놓이는 영역과, 그것을 2D 공간에서 그릴지 3D 세계에서 그릴지를 정합니다. 요소는 인터페이스를 이루는 이미지와 텍스트 같은 실제 조각들입니다.

## 레이아웃 및 위치 지정

보통의 엔티티와, 화면의 일부로 요소 컴포넌트를 쓰는 엔티티 사이의 큰 차이 하나는 부모를 기준으로 위치를 정하는 방식입니다. 요소 컴포넌트에는 최종 위치를 계산하는 방식을 바꾸는 두 가지 속성이 있습니다. `anchor` 속성은 자식이 부모를 기준으로 어디에 놓일지를 정하고, `pivot` 속성은 요소의 중심점이 어디인지를 정합니다. 자세한 내용은 [요소][3] 페이지에서 확인하세요.

## 그리기 순서

인터페이스의 그래픽 부분인 이미지와 텍스트 요소는 계층 구조에 나타나는 순서대로 그려집니다. 즉, 첫 번째 자식이 먼저 그려지고 그다음 자식이 이어서 그려집니다. 나중에 그려진 자식은 먼저 그려진 자식 위에 겹쳐 보입니다.

그리기 순서를 바꾸려면 에디터 계층 구조에서 엔티티의 순서를 다시 정렬하면 됩니다. `entity.reparent(...)`를 호출해 코드로 순서를 바꿀 수도 있습니다. 다만 이렇게 하면 화면 컴포넌트 전체의 그리기 순서가 다시 계산됩니다.

## 요소 9-슬라이싱

9-슬라이싱(또는 9-patch)은 하나의 비트맵 이미지를 늘여서 크기를 자유롭게 조절할 수 있는 인터페이스 요소로 만드는 그래픽 기법입니다. 텍스처 아틀라스와 스프라이트 에셋을 이용해 9-슬라이싱을 설정할 수 있습니다. [자세히 보기][5].

## 입력

UI 요소에서 입력을 처리하는 별도의 방법도 있습니다. 애플리케이션 객체에 `pc.ElementInput`의 인스턴스가 들어 있으며, 보통 `this.app.elementInput`으로 접근합니다. 이를 이용하면 요소 컴포넌트에서 직접 입력을 받을 수 있습니다. 예: `this.entity.element.on('click', ...)`. 자세한 내용은 [입력][4] 페이지에서 확인하세요.
