---
title: 이미지 요소 (Image Elements)
---

이미지 요소는 텍스처(그림)나 단색을 화면에 보여줄 때 사용합니다. 버튼처럼 더 복잡한 UI 부품을 만들 때 바탕으로 삼기에도 좋습니다.

## 틴팅 (Tinting)

이미지 요소마다 색상 속성이 하나씩 있습니다. 텍스처를 넣지 않으면 이미지 요소는 그냥 그 색으로 칠해진 사각형이 됩니다. 텍스처를 넣으면 이 색상이 텍스처에 색을 입히는 데(틴팅) 쓰입니다. 덕분에 흑백 텍스처 하나만 있어도 여러 가지 색으로 바꿔가며 쓸 수 있습니다.

![Tinting](/img/user-manual/user-interface/image-element/image-tinted.png)

## 투명도 (Transparency)

색상 속성처럼, 불투명도 속성을 이용하면 요소가 얼마나 투명하게 보일지 정할 수 있습니다.

![Transparent](/img/user-manual/user-interface/image-element/image-transparent.png)

## 고급 재질 (Advanced Materials)

텍스처, 색상, 불투명도 속성만으로 원하는 모습이 나오지 않을 때는, 재질 속성으로 이미지 요소에 직접 만든 재질을 지정할 수 있습니다. 화면에 제대로 그려지게 하려면, 이미지 요소에 넣는 모든 재질에서 _Depth Write를 꺼야_ 합니다.

:::note

화면 공간 요소는 조명이 생각대로 동작하지 않습니다. 그래서 화면 공간에서 쓰는 재질은 조명과 그림자를 꺼 두는 것이 좋습니다.

:::

## 마스크와 마스킹 (Masks and Masking)

이미지 요소로 그 아래에 있는 자식 요소들을 가리거나 숨길 수 있습니다. 이 기능을 켜려면 이미지 요소의 `mask` 속성을 true로 설정하세요.

마스크로 쓰는 이미지 요소에 텍스처 에셋이 없으면, 마스크는 너비와 높이로 정해지는 사각형이 됩니다. 텍스처가 있으면 그 텍스처의 알파 채널이 마스크로 쓰입니다. 다만 이미지 마스크는 1비트라는 점을 기억하세요. 즉 마스크의 가장자리가 알파 채널을 따라 서서히 흐려지지(페이드 아웃) 않고, 보이거나 안 보이거나 둘 중 하나입니다.
