---
title: 요소 (Elements)
---

요소는 사용자 인터페이스 화면을 이루는 하나하나의 조각입니다. 엔티티에 요소 컴포넌트를 붙이고, 그 엔티티를 화면 엔티티의 자식(또는 그 아래 하위 항목)으로 넣으면 인터페이스 요소가 만들어집니다. 화면에 속한 요소는 위치를 계산하는 방식이 보통의 엔티티와 다르고, 그래서 화면에서 놓이는 자리도 다르게 정해집니다.

부모를 기준으로 위치를 계산할 때 쓰는 로컬 위치, 회전, 스케일 외에도, 요소 컴포넌트는 앵커, 피벗, 마진이라는 속성을 함께 사용합니다. 이 속성들은 로컬 위치를 어디에서부터 재는지, 요소 사각형의 중심점이 어디인지, 그리고 요소 사각형의 가장자리와 앵커 사이의 거리가 얼마인지를 정합니다.

이 속성들 덕분에 인터페이스를 배치할 때 충분한 조절이 가능합니다. 예를 들어 여러 요소를 나란히 정렬하거나, 요소를 일정한 거리만큼 떨어뜨려 놓을 수 있습니다.

## 피벗 {#pivot}

요소의 피벗 속성은 위치, 회전, 스케일이 적용되는 기준점을 정합니다. 피벗은 0과 1 사이의 두 숫자로 나타내며, 요소의 전체 너비와 높이를 기준으로 X 방향과 Y 방향에서 피벗이 어디에 있는지를 정합니다. 예를 들어 `[0,0]`은 피벗을 요소의 왼쪽 아래에 두고, `[1,1]`은 피벗을 요소의 오른쪽 위에 둡니다.

![Pivot](/img/user-manual/user-interface/elements/pivot.png)

## 앵커 {#anchor}

앵커 속성은 요소의 위치를 계산할 때 기준으로 삼는 부모 위의 지점(또는 지점들)을 정합니다. 앵커 값은 `[minX, minY]`와 `[maxX, maxY]`라는 두 지점으로 지정합니다. 에디터에서는 네 개의 숫자로 표시됩니다: [minX, minY, maxX, maxY]

![Anchor](/img/user-manual/user-interface/elements/anchor-editor.png)

예를 들어 앵커를 `[0,0,0,0]`으로 설정하면 요소가 부모의 왼쪽 아래에 고정됩니다. 이때 요소의 위치 값은 그 왼쪽 아래 지점에서 얼마나 떨어져 있는지를 나타냅니다.

## 분할 앵커 {#split-anchors}

때로는 요소의 각 가장자리를 서로 다른 지점에 고정하는 것이 편리합니다. 예를 들어 해상도와 상관없이 화면을 꽉 채우도록 늘어나는 요소를 만들고 싶을 때가 그렇습니다. 앵커의 최소값과 최대값을 서로 다르게 나눠 주면 이렇게 만들 수 있습니다.

![Split Anchor](/img/user-manual/user-interface/elements/split-anchor.png)

이 그림에서는 앵커가 `[0,0,1,1]`로 설정되어 있어서, 요소의 각 가장자리를 부모의 각 가장자리에 고정하고 있습니다. 각 가장자리에는 50픽셀의 마진이 있으므로, 요소는 부모의 가장자리에서 50픽셀 안쪽까지 채우도록 고정됩니다.

## 마진 {#margin}

마진 속성은 어떤 축에서 앵커 값이 분할되어 있을 때만 쓸 수 있습니다. 마진은 앵커에서 요소의 가장자리까지를 화면 컴포넌트 기준 몇 픽셀로 둘지를 정합니다. 요소 컴포넌트의 스크립트에서는 마진 값을 간편하게 다룰 수 있도록 `left`, `right`, `top`, `bottom` 속성이 제공됩니다.

## 느슨한 요소 {#loose-elements}

요소는 주로 사용자 인터페이스 화면 컴포넌트의 일부로 쓰입니다. 하지만 화면에 속하지 않은 요소 컴포넌트를 둘 수도 있습니다. 예를 들어 월드 안에 떠 있는 하나의 텍스트 조각이 그렇습니다.

화면이 없는 요소는 크기와 위치를 정하는 방식이 조금 다릅니다. 화면에 속한 요소라면 32x32 요소가 32픽셀이지만, 화면이 없는 요소는 32m x 32m가 됩니다. 이 점을 감안해서 크기를 정하세요.
