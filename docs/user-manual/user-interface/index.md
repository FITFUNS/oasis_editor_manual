그래픽 애플리케이션에서 화면에 보이는 인터페이스를 만드는 일은 쉽지 않습니다. OasisW에서는 사용자 인터페이스를 만드는 방법이 여러 가지 있습니다.

## 화면 및 요소 컴포넌트 (권장)

![Intro](/img/user-manual/user-interface/user-interface-intro-sq.png)

OasisW에는 인터페이스를 만들 때 쓰는 두 가지 컴포넌트가 있고, 둘 다 WebGL 캔버스 안에서 바로 실행됩니다. [화면 컴포넌트][2]는 인터페이스를 담는 상자 역할을 하고, [요소 컴포넌트][3]는 그 안에 버튼이나 이미지 같은 인터페이스 조각을 넣을 때 씁니다. 이 방식의 가장 큰 장점은 인터페이스가 게임의 나머지 부분과 같은 공간 안에 함께 있다는 점입니다. 덕분에 애플리케이션과 인터페이스가 서로 자연스럽게 주고받을 수 있습니다.

## HTML과 CSS

웹 브라우저는 복잡한 화면을 빠르고 효율적으로 그려내기 위해 오랜 시간 동안 발전해 왔습니다. 그래서 어떤 경우에는 HTML, CSS, 그리고 브라우저 DOM을 이용해 인터페이스를 만드는 것이 더 잘 맞기도 합니다.

DOM을 쓸 때 가장 큰 단점은 성능입니다. DOM은 매 순간 화면을 빠르게 다시 그려야 하는 실시간 환경을 위해 만들어진 것이 아닙니다. 페이지를 다시 배치하는 작업이나 메모리 정리 작업 때문에 애플리케이션이 순간적으로 끊길 수 있습니다. 그래서 60fps를 꾸준히 유지하고 싶다면 이 방법은 최선이 아닙니다.
