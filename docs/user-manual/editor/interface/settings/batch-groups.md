배치 그룹은 여러 메쉬를 하나의 드로우 콜로 묶어, CPU가 할 일을 줄이고 렌더링을 더 빠르게 만듭니다.

:::note

이 설정은 지금 작업 중인 프로젝트 브랜치의 모든 사용자에게 영향을 줍니다.

:::

`BATCH GROUPS` 섹션으로 이동한 뒤 패널을 펼치세요:

![배치 그룹 설정](/img/user-manual/editor/interface/settings/batch-groups.webp)

아래는 사용할 수 있는 설정입니다:

## 배치 그룹 추가

- **Add Group** 버튼을 클릭해 새 배치 그룹을 만듭니다.
- 아래 속성들을 설정합니다:

| 설정 | 설명 |
| --- | --- |
| **Name** | 배치 그룹의 이름입니다. |
| **Dynamic** | 켜면 배치된 뒤에도 이 그룹의 오브젝트를 옮기거나 돌리거나 크기를 바꿀 수 있습니다. 절대 움직이지 않는 오브젝트라면 꺼 두는 것이 좋습니다. |
| **Max AABB** | 배치된 오브젝트들을 감싸는 상자의 축별 최대 크기입니다. 값을 크게 하면 더 많은 오브젝트를 한데 묶어 드로우 콜은 줄지만, 묶음이 커져 화면 밖 오브젝트를 걸러내는(컬링) 효율은 떨어질 수 있습니다. 값을 작게 하면 드로우 콜은 늘지만 작은 묶음이 생겨 컬링이 쉬워집니다. |
| **Layers** | 이 배치 그룹이 속할 레이어를 지정합니다. |

### 참고 사항

- 가능하면 항상 **정적 배치(static batching)** 를 써서 성능을 최대한 끌어올리세요.
- **Max AABB** 값을 너무 크게 잡지 마세요. 그래야 컬링 효율이 떨어지지 않습니다.
- 불필요한 배치를 막으려면, 실제로 관련 있는 레이어에만 배치 그룹을 지정하세요.
