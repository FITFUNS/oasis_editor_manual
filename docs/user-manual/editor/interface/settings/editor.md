에디터는 기본값만으로도 대부분의 사용자에게 잘 맞도록 설정되어 있습니다.
하지만 상황에 따라 에디터의 기본 동작을 바꾸고 싶을 때가 있습니다.

:::note

이 설정들은 나에게만 적용되며, 내 모든 프로젝트에 공통으로 쓰입니다.
또한 한 번 바꿔 두면 여러 세션에 걸쳐 그대로 유지(sticky)됩니다.

:::

`EDITOR` 섹션으로 이동한 뒤 패널을 펼치세요.

![Editor Settings](/img/user-manual/editor/interface/settings/editor.webp)

아래는 사용할 수 있는 설정 항목입니다: 

## 설정 {#settings}

| 설정                    | 설명               |
| ---------------------- | ---------------------------------------------------- |
| **Grid Divisions**     | 가로 방향으로 그리드 칸을 몇 개 그릴지 정합니다. 0으로 두면 그리드가 사라집니다.    |
| **Grid Division Size** | 그리드 칸 하나의 크기를 정합니다.                                         |
| **Snap**               | [기즈모](../viewport.md#gizmos) 스냅 간격을 정합니다. 기즈모를 쓰는 동안 Shift 키를 누르거나 툴바의 Snap 토글을 켜면 스냅이 작동합니다.                                  |
| **Camera Clip Near**   | 에디터 카메라의 Near 클립 값을 정합니다. 게임 실행에는 영향을 주지 않습니다.   |
| **Camera Clip Far**    | 에디터 카메라의 Far 클립 값을 정합니다. 게임 실행에는 영향을 주지 않습니다.    |
| **Zoom Sensitivity**   | 에디터 뷰포트에서 줌이 얼마나 빠르게 반응할지 정합니다.                                   |
| **Clear Color**        | 에디터 카메라의 배경(클리어) 색을 정합니다. 게임 실행에는 영향을 주지 않습니다.     |
| **Icons Size**         | 에디터 뷰포트에 보이는 아이콘 크기를 정합니다.                            |
