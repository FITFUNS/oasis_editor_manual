---
title: 라이트매핑 설정
sidebar_label: 라이트매핑
---

라이트매핑은 조명 효과를 미리 계산해 텍스처로 구워 두는 기능입니다. 여기서는 그 텍스처의 해상도, 부드럽게 다듬는 정도(필터링), 그리고 그늘진 부분을 표현하는 앰비언트 오클루전을 조정합니다.

:::note

이 설정은 현재 활성화된 프로젝트 브랜치의 모든 사용자에게 영향을 줍니다.

:::

`LIGHTMAPPING` 섹션으로 이동한 뒤 패널을 펼치세요:

![라이트매핑 설정](/img/user-manual/editor/interface/settings/lightmapping.webp)

아래는 사용 가능한 설정에 대한 설명입니다:

## 일반

| 설정 | 설명 |
| --- | --- |
| **Size Multiplier** | 라이트맵 텍스처의 해상도는 오브젝트가 실제로 차지하는 면적과 모델·씬의 크기를 바탕으로 자동으로 정해집니다. 이 값을 올리거나 내리면 씬 전체 라이트맵의 해상도가 함께 바뀝니다. |
| **Max Resolution** | 자동으로 만들어지는 라이트맵 텍스처가 가질 수 있는 최대 해상도입니다. |
| **Mode** | 라이트맵을 굽는 방식입니다:<ul><li><strong>Color Only</strong>: 색상만 담은 라이트맵</li><li><strong>Color and Direction</strong>: 색상에 더해 주된 빛의 방향 정보까지 담음(범프/스페큘러 표현에 사용)</li></ul> |

## 필터링

| 설정 | 설명 |
| --- | --- |
| **Filter** | 실행 중에 구워 둔 라이트맵을 양방향(bilateral) 필터로 부드럽게 다듬습니다. |
| **Range** | 양방향 필터가 얼마나 넓은 범위까지 다듬을지 정하는 값입니다. |
| **Smoothness** | 양방향 필터가 공간적으로 얼마나 부드럽게 처리할지 정하는 값입니다. |

## 앰비언트 베이크

| 설정 | 설명 |
| --- | --- |
| **Ambient Bake** | 주변에서 은은하게 퍼지는 빛(앰비언트 라이트)을 라이트맵에 함께 구워 넣습니다. |
| **Samples** | 앰비언트 라이트를 구울 때 쓸 샘플 개수입니다. 많을수록 결과가 깔끔해집니다. |
| **Sphere Part** | 앰비언트 라이트를 구울 때 주변 구체 중 얼마만큼의 범위를 포함할지 정하는 비율입니다. |
| **Occlusion Brightness** | 구워진 앰비언트 오클루전(그늘진 부분)의 밝기입니다. |
| **Occlusion Contrast** | 구워진 앰비언트 오클루전(그늘진 부분)의 대비입니다. |
