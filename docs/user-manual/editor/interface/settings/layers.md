레이어는 오브젝트들을 묶어서 관리하는 그룹으로, 어떤 오브젝트끼리 함께 그려지고 어떤 순서로 그려질지를 정합니다.

:::note

이 설정은 현재 활성화된 프로젝트 브랜치의 모든 사용자에게 영향을 줍니다.

:::

`LAYERS` 섹션으로 이동한 뒤 패널을 펼치세요:

![레이어 설정](/img/user-manual/editor/interface/settings/layers.webp)

아래는 사용 가능한 설정에 대한 설명입니다:

## 레이어

- **Add Layer**: 씬 오브젝트를 정리하는 데 쓸 새 레이어를 만듭니다.
- 각 레이어는 이름을 바꾸거나 지울 수 있습니다.

기본으로 들어 있는 레이어:

- **World**
- **Depth**
- **Skybox**
- **Immediate**
- **UI**

## 렌더 순서

레이어를 그리는 순서를 정하는 곳으로, 불투명한 것을 그리는 단계와 투명한 것을 그리는 단계를 나눠서 다룹니다.

| 설정 | 설명 |
| --- | --- |
| **Layer** | 렌더 레이어의 이름입니다. |
| **Pass** | 다음 중 하나입니다:<ul><li><strong>불투명(Opaque)</strong>: 속이 비치지 않는 메쉬를 그립니다</li><li><strong>투명(Transparent)</strong>: 반투명하게 비치는 메쉬를 그립니다</li></ul> |
| **Enabled** | 해당 레이어의 이 단계를 켜거나 끕니다. 끄면 그 단계의 메쉬는 화면에 그려지지 않습니다. |

### 참고

- 투명한 오브젝트는 제대로 보이려면 불투명한 오브젝트를 다 그린 뒤에 그려야 합니다.
- **Render Order** 목록에서 항목을 드래그하면 레이어 순서를 바꿀 수 있습니다.
