물체가 떨어지고 부딪히는 등, 프로젝트 전체의 물리 동작을 정하는 설정입니다.

:::note

이 설정들은 프로젝트에서 현재 활성화된 브랜치의 모든 사용자에게 적용됩니다.

:::

`PHYSICS` 섹션으로 이동한 뒤 패널을 확장하세요:

![Physics Settings](/img/user-manual/editor/interface/settings/physics.webp)

사용할 수 있는 설정 항목은 다음과 같습니다:

## 설정

| 설정                  | 설명                |
| -------------------- | ------------------ |
| **Physics Library** | 물리 기능을 쓰는 데 필요한 Ammo asm.js 및 WebAssembly 모듈을 이 프로젝트에 추가합니다.                |
| **Gravity**         | 씬에 있는 모든 리지드 바디를 매 프레임 잡아당기는 중력의 세기와 방향입니다. 기본값은 초당 제곱미터 -9.8로, 지구 중력과 비슷합니다. 우주처럼 무중력 공간을 만들고 싶다면 0, 0, 0으로 설정하면 됩니다. |

### 참고 사항

- Ammo.js를 가져오지 않으면 물리 기능이 동작하지 않습니다.
- 중력 값을 바꾸면 지구, 달, 우주처럼 서로 다른 환경을 흉내 낼 수 있습니다.
