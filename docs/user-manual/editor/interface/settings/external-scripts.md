**외부 스크립트** 설정을 쓰면 다른 곳에서 만든 JavaScript 라이브러리를 프로젝트에 불러올 수 있습니다. 이렇게 불러온 코드는 에디터에서도, 실제로 실행되는 앱에서도 그대로 쓸 수 있습니다.

:::note

이 설정은 현재 활성화된 프로젝트 브랜치의 모든 사용자에게 영향을 줍니다.

:::

`EXTERNAL SCRIPTS` 섹션으로 이동한 뒤 패널을 펼치세요:

![외부 스크립트 설정](/img/user-manual/editor/interface/settings/external-scripts.png)

## 사용 방법

* 불러올 스크립트가 몇 개인지 **URLs** 칸에 숫자로 적습니다.
* 그러면 URL 입력 칸이 그 개수만큼 생깁니다. 각 칸에 라이브러리 주소(URL)를 넣습니다.

이렇게 넣은 라이브러리는 프로젝트에 함께 불러와지고, 에디터와 앱 코드에서 바로 가져다 쓸 수 있습니다.

## 활용 예시

- 외부 수학/물리 라이브러리 로드
- 유틸리티 스크립트(CSV 파서, 압축 라이브러리 등) 사용
