앱이 어떤 입력 장치(키보드, 마우스, 터치, 게임패드)를 받아들일지 켜고 끄는 곳입니다. 쓰지 않을 장치를 꺼 두면 그 입력은 무시됩니다.

:::note

이 설정은 현재 활성화된 프로젝트 브랜치의 모든 사용자에게 적용됩니다.

:::

`INPUT` 섹션으로 이동한 뒤 패널을 펼치세요:

![Input Settings](/img/user-manual/editor/interface/settings/input.webp)

사용 가능한 설정은 다음과 같습니다:

## 설정

| 설정 | 설명 |
| --- | --- |
| **Keyboard** | 키보드 입력을 켭니다. 끄면 앱이 키보드 입력을 받지 않습니다. |
| **Mouse** | 마우스 입력을 켭니다. 끄면 마우스 입력을 받지 않습니다. |
| **Touch** | 터치 입력을 켭니다. 끄면 터치 입력을 받지 않습니다. |
| **Gamepads** | 게임패드 입력을 켭니다. 끄면 게임패드 입력을 받지 않습니다. |

### 참고 사항

- 쓰지 않는 입력 방식을 꺼 두면 그만큼 이벤트를 덜 처리하게 되어 성능에 도움이 됩니다.
