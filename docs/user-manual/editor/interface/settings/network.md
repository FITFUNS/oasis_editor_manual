에셋을 내려받다가 실패했을 때, 다시 시도하는 방식을 정하는 설정입니다.

:::note

이 설정은 현재 활성화된 프로젝트 브랜치의 모든 사용자에게 적용됩니다.

:::

`NETWORK` 섹션으로 이동한 뒤 패널을 펼치세요:

![Network Settings](/img/user-manual/editor/interface/settings/network.webp)

사용할 수 있는 설정은 다음과 같습니다:

## 설정

| 설정 | 설명 |
| --- | --- |
| **Asset Retries** | 에셋을 내려받지 못했을 때 다시 시도하는 최대 횟수입니다. 요청이 실패하면 시도할 때마다 대기 시간을 조금씩 늘려 가며(지수 백오프) 다시 받아옵니다. |

### 참고 사항

- 재시도 횟수를 늘리면 네트워크가 불안정한 환경에서도 더 잘 버티지만, 그만큼 사용자에게 오류가 보이기까지 시간이 더 걸릴 수 있습니다.
