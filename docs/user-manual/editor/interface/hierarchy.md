# Hierarchy

하이어라키 뷰는 씬 안에 있는 모든 오브젝트를 계층 구조로 한눈에 보고 정리하는 곳입니다.

![Hierarchy](/img/usage-guide/4_hierarchy.png)

## 엔티티 생성 및 삭제

- **생성**: 하이어라키 뷰에서 엔티티를 고른 뒤, 그 아래에 **새 하위 엔티티**를 만듭니다.  
- **삭제**: 고른 엔티티를 지웁니다.  
- **방법**: 하이어라키 뷰 오른쪽 위의 버튼을 쓰거나, 엔티티를 **마우스 오른쪽 클릭**해 나오는 메뉴를 씁니다.

## Hierarchy 구성하기

- 씬(Scene)은 계층 구조로 되어 있어서, 엔티티끼리 **부모-자식 관계**를 맺을 수 있습니다.
- 부모 엔티티의 **변환 행렬(Transform matrix)** 은 자식 엔티티에 그대로 이어집니다.
  - 부모를 옮기거나 돌리면 자식도 같이 옮겨지고 돌아갑니다.
  - 여러 엔티티를 한꺼번에 다룰 때 편리합니다.
- **드래그 앤 드롭**으로 하이어라키 구조를 바꿉니다.
  - 엔티티를 다른 엔티티의 자식으로 옮깁니다(리패런트, Reparent).

## Hierarchy 검색하기

- 하이어라키 뷰 위쪽의 **검색 상자(Search Box)** 로 엔티티 목록을 걸러 볼 수 있습니다.

![Hierarchy](/img/usage-guide/4_2_search_box.png)

## 엔티티 복제하기

- **단축키**: Ctrl+D (Mac은 Cmd+D)  
- **방법**: 엔티티 선택 → 복제 → 원본 바로 옆에 똑같은 것이 하나 더 생깁니다.
- **우클릭 메뉴**: `Duplicate`를 고릅니다.

## 엔티티 복사 / 붙여넣기

- **같은 씬 안에서**:
  1. 복사할 엔티티를 고릅니다.
  2. **Ctrl+C** (Mac은 Cmd+C)를 누릅니다.
  3. 붙여넣을 부모 엔티티를 고릅니다.
  4. **Ctrl+V** (Mac은 Cmd+V)를 누릅니다.
- **다른 씬이나 다른 프로젝트로**:
  1. 복사(Ctrl+C)합니다.
  2. 다른 씬/프로젝트로 이동합니다.
  3. 부모 엔티티를 고른 뒤 붙여넣기(Ctrl+V)합니다.

## 엔티티 생성 및 카테고리 구조

- 하이어라키 뷰에서 마우스 오른쪽 버튼을 누르면 2D, 3D, Audio, Camera, Light, User Interface, Server Side처럼 쓰임새별로 나뉜 엔티티 생성 메뉴가 나옵니다.
- 각 카테고리는 기본 컴포넌트가 미리 들어 있는 엔티티를 만들어 주며, 만든 뒤에는 인스팩터에서 세부 설정을 바꿀 수 있습니다.
- 하이어라키 뷰 메뉴에 나오는 각 엔티티 유형과 컴포넌트의 자세한 설명은 [**컴포넌트**](/user-manual/scenes/components) 에서 볼 수 있습니다.
