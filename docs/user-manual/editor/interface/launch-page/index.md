---
title: 실행 페이지
---

에디터의 뷰포트(Viewport)는 애플리케이션을 눈으로 보며 꾸미는 공간입니다. 여기서 Launch 버튼을 누르면 실행 페이지(Launch Page)가 새로 열리고, 만든 애플리케이션을 실제로 돌려볼 수 있습니다.

![Launch Button](/img/user-manual/editor/launch-page/launch-button.png)

## 실행 페이지 사용하기

실행 페이지는 새 탭에서 열립니다. 에디터 탭과 실행 페이지 탭을 자유롭게 오가며 작업해도 괜찮습니다.
화면이 넓거나 모니터가 여러 개라면, 실행 페이지 탭을 따로 떼어 에디터와 나란히 놓고 쓰는 것을 추천합니다.

![Launch Page Side by Side](/img/user-manual/editor/launch-page/launch-page-side-by-side.png)

이렇게 두면 두 화면을 더 빠르고 편하게 오갈 수 있습니다.

## 실시간 업데이트

실행 페이지의 가장 편리한 점은 에디터와 실시간으로 연결(라이브 링크)되어 있다는 것입니다.
에디터에서 무언가를 바꾸면 그 결과가 실행 페이지에 곧바로 나타납니다.

![Launch Page Live Link](/img/user-manual/editor/launch-page/launch-page-live-link.gif)

같은 에디터에 함께 접속해 있는 다른 사용자(쓰기 권한이 있는 경우)가 수정한 내용도 실행 페이지에 바로 반영됩니다.
