# 인터페이스

OasisW를 처음 켰을 때 보이는 화면과 기본 도구들을 하나씩 살펴봅니다.

## 씬 열기

프로젝트를 열면 먼저 씬을 고르는 화면이 나옵니다. 여기서 원하는 씬을 클릭하면 작업이 시작됩니다.

![프로젝트 열기 화면](/img/usage-guide/1_open_project.png)

씬이 열리면 여러 도구와 뷰가 나타나고, 이때부터 게임을 만들 수 있습니다.

## 메인 인터페이스

![OasisW 전체 화면](/img/usage-guide/2_full.png)

### [1. Toolbar](/user-manual/editor/interface/toolbar)
툴바에 있는 버튼들과 추가 도구를 어떻게 쓰는지 알아봅니다.

### [2. Project Toolbar](/user-manual/editor/interface/project-toolbar)
프로젝트 툴바에서 프로젝트를 관리할 때 쓰는 도구들을 알아봅니다.

### [3. Hierarchy](/user-manual/editor/interface/hierarchy)
하이어라키 뷰에서 다루는 Entity 종류와, 계층 구조를 정리하는 방법을 알아봅니다.

### [4. Viewport](/user-manual/editor/interface/viewport)
뷰포트의 여러 보기 모드와 조작 방법, 렌더링 옵션을 알아봅니다.

### [5. Inspector](/user-manual/editor/interface/inspector)
인스팩터 뷰에서 컴포넌트 목록을 보고 속성을 바꾸며 컴포넌트를 관리하는 방법을 알아봅니다.

### [6. Assets](/user-manual/editor/interface/assets)
에셋 뷰에서 다루는 에셋 종류와 폴더 정리 팁, 에셋을 가볍게 만드는 방법을 알아봅니다.
