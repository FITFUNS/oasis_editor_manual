# Assets

에셋 뷰는 프로젝트에서 쓰는 모든 리소스를 한곳에 모아 두는 창고입니다.  
이곳에서 에셋을 새로 만들고, 올리고, 지우고, 살펴보고, 편집할 수 있습니다.

![Assets](/img/usage-guide/6_assets.png)

## 폴더 계층 구조

- 폴더 뷰에서는 에셋을 폴더로 나눠 트리 모양으로 정리합니다.
- 새 폴더 만들기  
  - **Add Asset(+)** 버튼을 누른 뒤 **Folder**를 고릅니다.  
  - 또는 원하는 폴더에서 우클릭 → **New Asset → Folder**를 고릅니다.
- 폴더 이름 바꾸기  
  - 폴더 뷰에서 폴더를 클릭한 뒤 **인스팩터**에서 이름을 고칩니다.
- 폴더 지우기  
  - 폴더 뷰에서 폴더를 클릭 → **Delete**를 누릅니다.  
  - 또는 폴더를 우클릭 → **Delete**를 누릅니다.
- 폴더끼리 드래그 앤 드롭해서 구조를 다시 짤 수 있습니다.

## 에셋 생성 및 업로드

- 컴퓨터에 있는 파일을 에셋 뷰로 끌어다 놓으면 자동으로 올라가고 임포트됩니다.
- 일부 에셋은 **Add Asset(+)** 아이콘으로 직접 만들 수 있습니다.
- 에셋을 지우려면 우클릭 → **Delete**를 누릅니다.

## 에셋 편집

- 글자로 된 에셋(text, json, shader, html, css, script)은 더블 클릭하면 열려서 바로 고칠 수 있습니다.
- AI로 코드를 만들어 적용할 수도 있습니다.
- **AI 상세 가이드**: [코드 제네레이션](/usage-guide/code-generation)을 참조하세요.

## 에셋 정보 표시

- 에셋 썸네일을 고르면 인스팩터에 그 에셋의 자세한 정보가 나옵니다.

## 필터링

- 필터 드롭다운 메뉴에서 보고 싶은 에셋 유형만 골라 볼 수 있습니다.

![Assets](/img/usage-guide/6_1_filtering.png)

## 검색

- 검색창에 입력하면 프로젝트 안의 에셋이 바로바로 걸러집니다.

![Assets](/img/usage-guide/6_2_searching.png)

- 검색 유형
  - **ID**: 고유 ID를 넣으면 딱 그것과 일치하는 에셋만 나옵니다.
  - **RegExp**: 검색어 앞에 `*`를 붙이면 정규표현식을 쓸 수 있습니다.  
    예) `*.*`는 모든 에셋을 찾습니다.

## 드래그 앤 드롭

- 에셋을 폴더 안으로 끌어다 놓아 옮길 수 있습니다.  
- 여러 개를 한 번에 고를 수도 있습니다 (Ctrl+A로 지금 폴더 안의 에셋을 모두 선택).  
- 인스팩터의 에셋 슬롯(컴포넌트 속성이나 스크립트 속성)으로도 끌어다 놓을 수 있습니다.  
- 모델, 재질, 큐브맵 에셋은 뷰포트에 바로 끌어다 놓을 수 있습니다.

## 프로젝트 간 복사 & 붙여넣기

- 에셋 하나 또는 여러 개를 고른 뒤 우클릭 → **Copy**를 누릅니다.
- 붙여넣을 프로젝트의 에셋 뷰에서 우클릭 → **Paste**를 누릅니다.
- 복사할 때는 그 에셋이 참조하는 것들(예: 모델이 쓰는 재질, 텍스처 등)도 함께 복사됩니다.  
- 같은 이름의 에셋이 이미 있어도 덮어쓰지 않고 새 에셋으로 만듭니다.
