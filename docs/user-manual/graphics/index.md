title: 그래픽스 (Graphics)
---

OasisW에는 웹에서 3D 화면을 빠르고 멋지게 그려 주는 그래픽스 엔진이 들어 있습니다. 이 엔진은 [WebGL](https://developer.mozilla.org/en-US/docs/Web/API/WebGL_API)과 [WebGPU](https://developer.mozilla.org/en-US/docs/Web/API/WebGPU_API)를 모두 지원하기 때문에, 최신 기능을 쓰면서도 요즘 나오는 브라우저 어디에서나 잘 돌아갑니다.

## 그래픽스 엔진 백엔드

OasisW 엔진은 화면을 그리는 방식(백엔드)을 여러 가지 지원합니다:

* **WebGPU (베타)** - 가장 새로운 그래픽스 방식으로, 처리 부담이 적고 컴퓨트 셰이더도 쓸 수 있습니다
* **WebGL 2.0** - 오래 검증되어 안정적이며, 거의 모든 브라우저와 기기에서 [폭넓게 지원](https://caniuse.com/webgl2)됩니다
* **Null** - 화면 없이 돌아가는 환경(예: Node)에서 엔진을 실행할 때 씁니다

:::note[자동 폴백]

브라우저가 WebGPU를 지원하지 않으면 엔진이 알아서 WebGL로 자연스럽게 바꿔 줍니다.

:::

## 주요 렌더링 기능

### 물리 기반 렌더링 (PBR)

* metallic/roughness 방식과 specular/glossiness 방식 두 가지 워크플로우로 PBR을 폭넓게 지원합니다
* 빛 에너지를 유지하면서 실제 물리 법칙에 맞게 조명을 계산합니다
* 클리어코트, 이방성, 시인, 투과 같은 재질을 표현할 수 있습니다

### 고급 조명

* **클러스터 조명 시스템** - 수백 개의 움직이는 조명도 효율적으로 처리합니다
* 그림자와 쿠키를 자유롭게 설정할 수 있는 **방향성, 점, 스팟 조명**
* **영역 조명** - 직사각형, 디스크, 구 모양의 광원으로 더 사실적인 빛을 만듭니다
* HDR 환경 맵으로 주변 빛을 표현하는 **이미지 기반 조명 (IBL)**
* 정적 조명을 최적화하는 **런타임 라이트맵 생성**

### 높은 동적 범위 (HDR) 렌더링

* 감마 보정이 자동으로 적용되는 **선형 워크플로우**
* 지원되는 기기에서 **HDR 디스플레이 출력** 사용 가능
* ACES, Neutral, Linear 등 다양한 **고급 톤 매핑** 방식
* 후처리 효과를 두루 다룰 수 있는 **CameraFrame 시스템**

### 현대적 렌더링 파이프라인

* 고급 효과를 쓸 수 있게 해 주는 **렌더 패스 아키텍처**
* **다중 렌더 타겟 (MRT)** 지원
* **깊이 사전 패스**와 **시간적 안티앨리어싱 (TAA)**
* 똑같은 모양을 여러 번 그릴 때 효율적인 **하드웨어 인스턴싱**
* 그리기 명령(드로우 콜)을 줄여 주는 **정적 및 동적 배칭**

### 후처리 효과

CameraFrame 시스템은 화면을 다 그린 뒤에 입히는 효과를 두루 갖추고 있습니다:

* 빛이 번지는 모습을 물리적으로 정확하게 표현하는 **HDR 블룸**
* **스크린 공간 앰비언트 오클루전 (SSAO)**
* 배경이 뿌옇게 흐려지는 보케 효과를 내는 **피사계 심도 (DoF)**
* 가장자리를 매끄럽게 다듬는 **시간적 안티앨리어싱 (TAA)**
* **비네트, 세피아, 밝기/대비** 조절과 컬러 그레이딩

### 고급 렌더링 기법

<!-- * 사실적인 장면 재구성을 위한 **3D 가우시안 스플래팅** -->
* 특수 효과에 쓰는 **하드웨어 가속 파티클**
* 캐릭터 애니메이션을 위한 **메시 스키닝 및 모핑**
* 최적화된 기본 도형으로 만드는 **절차적 지오메트리 생성**

### 사용자 정의 셰이더

* GLSL (WebGL)과 WGSL (WebGPU)을 모두 지원하는 **유연한 셰이더 시스템**
* 조각(청크)을 조합해 셰이더를 자동으로 만들어 주는 기능
* 셰이더 변형과 인클루드를 처리하는 **전처리기 지원**
* GPU로 계산을 빠르게 돌리는 **WebGPU 컴퓨트 셰이더**

그래픽스 엔진은 최신 웹 표준과 하드웨어 기능을 계속 반영하도록 꾸준히 업데이트됩니다. 덕분에 OasisW로 만든 애플리케이션은 어떤 플랫폼에서든 뛰어난 화질과 성능을 낼 수 있습니다.
