---
title: 에셋 (Assets)
---

에셋은 게임에서 사용할 수 있는 **재료**입니다. 3D 모델, 이미지, 소리, 글꼴, 스크립트처럼 화면에 보이거나 들리는 것은 거의 모두 에셋입니다. 씬(Scene)이 '무대'라면 에셋은 그 무대에 올릴 '소품'이라고 생각하면 이해하기 쉽습니다.

파일을 업로드하면 곧바로 게임에 쓰이는 것이 아니라, **가져오기 파이프라인(import pipeline)**을 한 번 거칩니다. 이 과정에서 파일이 웹에서 빠르게 동작하도록 변환되고 최적화됩니다.

## 에셋 패널 둘러보기

에디터 아래쪽에 있는 **ASSETS** 패널에서 프로젝트의 모든 에셋을 관리합니다. 실제 화면은 다음과 같이 구성되어 있습니다.

- **경로와 개수** — 왼쪽 위에 `assets`처럼 현재 폴더 경로와 `5 items`처럼 항목 수가 표시됩니다. 폴더 안으로 들어가면 `assets / ammo.js`처럼 경로가 이어집니다.
- **+ 버튼** — 새 에셋을 만들거나 파일을 업로드합니다.
- **타입 필터** — `All`로 되어 있는 드롭다운에서 특정 유형만 골라 볼 수 있습니다.
- **Search** — 이름으로 에셋을 찾습니다.
- **TYPE 줄** — 현재 폴더에 어떤 유형이 몇 개 있는지 자동으로 요약해 줍니다. 이 칩을 눌러도 필터가 걸립니다.
- **목록** — `Name` · `Type` · `Size` 세 칸으로 표시되며, 칸 제목을 누르면 정렬됩니다.
- **왼쪽 트리** — 폴더 구조를 보여 줍니다. 폴더 이름 오른쪽의 숫자는 그 안의 항목 수입니다.

## 유형

OasisW는 여러 콘텐츠 유형을 지원합니다. 대표적인 것들은 다음과 같습니다.

- 모델 (예: `.fbx`, `.glb`)
- 3D 애니메이션
- 텍스처용 이미지 (예: `.jpg`, `.png`)
- 오디오 (예: `.mp3`, `.ogg`)

새 파일을 업로드하면 **파일 확장자를 보고 에셋 유형이 자동으로 정해집니다**. 예를 들어 PNG 파일을 올리면 `texture` 유형의 에셋이 만들어집니다. 유형을 직접 고를 필요는 없습니다.

전체 유형 목록과 각 유형이 어떤 확장자에서 만들어지는지는 [에셋 유형](/user-manual/assets/types) 페이지에 정리되어 있습니다.

## Source 에셋과 Target 에셋

에셋 유형 다음으로 중요한 성질은 그 에셋이 **Source**인지 **Target**인지입니다.

- **Source 에셋** — 내가 업로드한 *원본 파일* 그 자체입니다.
- **Target 에셋** — 가져오기 파이프라인이 원본을 변환·최적화해서 *새로 만들어 낸 결과물*입니다.

예를 들어 텍스처로 쓸 Photoshop(PSD) 파일을 업로드하면, 먼저 그 PSD를 가리키는 `texture` 유형의 **Source 에셋**이 생깁니다. 이어서 파이프라인이 PSD를 JPG로 변환하고, 그 JPG를 가리키는 `texture` 유형의 **Target 에셋**을 만듭니다.

:::note 기억해 두십시오

에디터와 게임에서 실제로 참조하는 것은 **언제나 Target 에셋**입니다. 런타임에 바로 쓸 수 있도록 최적화된 형태이기 때문입니다. Source 에셋은 "원본을 보관해 둔 것"이라고 생각하면 됩니다.

:::

:::tip 에디터에서 확인하기

에셋 패널의 타입 필터를 열어 보면 `Model`과 `Model (source)`, `Texture`와 `Texture (source)`처럼 **같은 유형이 두 줄씩** 있는 것을 볼 수 있습니다. `(source)`가 붙은 쪽이 Source 에셋, 붙지 않은 쪽이 Target 에셋입니다. 이 개념이 화면에 그대로 드러나는 자리입니다.

:::

## 에셋 속성 살펴보기

에셋을 하나 선택하면 오른쪽 **인스팩터**에 그 에셋의 속성이 나타납니다. 유형과 관계없이 공통으로 보이는 항목은 다음과 같습니다.

| 속성 | 설명 |
|---|---|
| `ID` | 에셋마다 부여되는 고유 번호입니다. 스크립트에서 에셋을 찾을 때 쓰입니다. |
| `Name` | 에셋 이름입니다. 이 칸에서 바로 고칠 수 있습니다. |
| `Tags` | 에셋에 붙이는 꼬리표입니다. 여러 에셋을 한 묶음으로 다룰 때 씁니다. [에셋 태그](/user-manual/assets/preloading-and-streaming)를 참고하십시오. |
| `Runtime` | 런타임에서 사용할 수 있는 에셋인지 표시합니다. |
| `Type` | 에셋 유형입니다. 업로드할 때 자동으로 정해지며 바꿀 수 없습니다. |
| `Exclude` | 체크하면 이 에셋을 게시 결과물에서 제외합니다. |
| `Preload` | 애플리케이션이 시작되기 전에 미리 내려받을지 정합니다. 기본값은 켜짐입니다. |
| `Size` | 파일 크기입니다. |
| `Source` | 이 에셋을 만들어 낸 Source 에셋입니다. 원본이 없으면 `none`으로 표시됩니다. |
| `Created` | 만들어진 날짜와 시각입니다. |

속성 이름 옆의 **?** 를 누르면 그 속성의 설명과 **API REFERENCE** 링크가 담긴 도움말이 열립니다. 이름이 낯선 속성을 만나면 먼저 눌러 보십시오.

속성 아래에는 **DOWNLOAD** 버튼이 있어 원본 파일을 내려받을 수 있습니다. 스크립트 에셋에는 **EDIT** 버튼이, 텍스처 에셋에는 `Width` · `Height` · `sRGB` · `Mipmaps` 같은 유형별 항목이 함께 나타납니다.

## 가져오기 파이프라인 설정

파일을 올렸을 때 파이프라인이 어떻게 동작할지는 프로젝트 설정에서 조절합니다. 오른쪽 위 **톱니바퀴** 아이콘을 눌러 **SETTINGS**를 열고 **ASSET TASKS** 항목을 펼치십시오.

| 설정 | 기본값 | 설명 |
|---|---|---|
| `Create Atlases` | 꺼짐 | 업로드한 이미지로 텍스처 아틀라스를 자동 생성합니다. |
| `Create FBX Folder` | 켜짐 | FBX를 올릴 때 결과 에셋들을 담을 폴더를 자동으로 만듭니다. |
| `Server-side GLB Decompose` | 켜짐 | GLB 파일을 서버에서 분해해 템플릿·렌더·재질·텍스처 에셋으로 나눕니다. |

:::warning 주의하시기 바랍니다

이 설정은 **앞으로 업로드할 파일**에만 적용됩니다. 이미 올려 둔 에셋에는 소급 적용되지 않으므로, 설정을 바꾼 뒤에는 필요한 파일을 다시 업로드해야 합니다.

:::

## 폴더로 정리하기

에셋이 몇십 개만 넘어가도 목록에서 원하는 것을 찾기가 어려워집니다. 처음부터 폴더로 나눠 두면 훨씬 편합니다.

1. 에셋 패널의 **+** 버튼을 누르고 **Folder**를 선택합니다.
2. 이름을 입력하고 `Enter`를 누릅니다.
3. 에셋을 폴더 위로 끌어다 놓으면 옮겨집니다.

왼쪽 트리에서 폴더를 클릭하면 그 안으로 들어가고, 위쪽 경로 표시가 `assets / ammo.js`처럼 바뀝니다. 이때 TYPE 줄도 그 폴더의 내용에 맞게 다시 계산됩니다.

:::tip 팁

물리 엔진에서 쓰는 `ammo.js`처럼, 여러 파일이 한 세트로 움직이는 에셋은 이미 폴더로 묶여 있습니다. 이런 폴더는 그대로 두는 편이 안전합니다.

:::
