![텍스처 아틀라스](/img/user-manual/assets/texture-atlas/texture-atlas.jpg)

텍스처 아틀라스 에셋은 **텍스처 안의 '프레임'을 설명하는 데이터가 추가된 텍스처 에셋**입니다. 프레임은 텍스처에서 직사각형으로 정의된 영역이며, 위치와 회전의 기준이 되는 **피벗** 지점을 가집니다.

텍스처 아틀라스는 일반 [텍스처 에셋](/user-manual/assets/types/texture)에서 **마우스 오른쪽 클릭** 후 **아틀라스 생성**을 선택해 만듭니다. 또는 기본 에셋 설정을 바꿔 아틀라스 생성을 자동으로 켤 수도 있습니다.

텍스처 아틀라스는 [스프라이트 에셋](/user-manual/assets/types/sprite)과 함께 사용되어 2D 그래픽을 그립니다.

:::note 왜 한 장에 모으나요

이미지를 100장 따로 불러오는 것보다 **한 장에 모아 한 번에 불러오는 편이 훨씬 빠릅니다.** 그리는 횟수도 줄어들어 성능에 유리합니다. 캐릭터의 걷기 동작 8프레임처럼 함께 쓰이는 그림들을 한 장에 담아 두는 것이 일반적입니다.

:::

## 속성

### 프레임

텍스처 아틀라스의 프레임은 **고유한 값**(보통 정수 문자열)으로 키가 지정됩니다. 프레임의 형식은 다음과 같습니다.

```javascript
{
    rect: [0, 0, 0, 0],  // u, v, width, height - 너비와 높이는 픽셀 단위
    pivot: [0, 0],       // x, y - 0-1 비율로 표현
    border: [0, 0, 0, 0] // left, bottom, right, top - 픽셀 단위
}
```

| 항목 | 의미 |
| --- | --- |
| `rect` | 아틀라스에서 잘라 낼 사각형입니다. `u`, `v`는 시작 위치이고 너비와 높이는 픽셀 단위입니다. |
| `pivot` | 위치와 회전의 기준점입니다. 0에서 1 사이의 비율로 표현합니다. `[0.5, 0.5]`가 가운데입니다. |
| `border` | 9-슬라이싱에 쓰이는 테두리 두께입니다. 왼쪽 · 아래 · 오른쪽 · 위 순서이며 픽셀 단위입니다. |

### 텍스처 속성

프레임 데이터 외에, 텍스처 아틀라스는 [텍스처 에셋](/user-manual/assets/types/texture)의 속성도 그대로 가지고 있습니다. 필터링과 이방성 등을 같은 방식으로 조절할 수 있습니다.
