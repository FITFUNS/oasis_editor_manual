---
title: 스프라이트 (Sprite)
---

스프라이트는 씬에 그릴 수 있는 **2D 그래픽**입니다. 스프라이트 에셋은 [텍스처 아틀라스](/user-manual/assets/types/texture-atlas)와 그 아틀라스 안의 **프레임 순서**에 대한 참조입니다. 덕분에 스프라이트는 아틀라스에서 잘라 낸 **한 장의 이미지**일 수도 있고, 여러 프레임을 이어 붙인 **플립북 방식의 애니메이션**일 수도 있습니다.

## 속성

![스프라이트 속성](/img/user-manual/assets/sprites/sprites.jpg)

### Pixels Per Unit

OasisW 씬에서 **1 유닛에 대응하는 스프라이트 이미지의 픽셀 수**입니다. 예를 들어 `pixelsPerUnit`이 1이고 스프라이트가 32×32라면, 씬에 그려질 때 너비와 높이가 각각 32 유닛이 됩니다.

기본적으로 *Simple* 렌더 모드의 스프라이트는 `pixelsPerUnit`이 **100**으로 설정되어 만들어집니다. 즉 100×100 스프라이트가 씬에서 1 유닛 크기를 가집니다.

*Sliced* 스프라이트를 만들면 기본값이 **1**로 설정됩니다. 이런 스프라이트는 보통 사용자 인터페이스를 만들 때 화면(Screen) 컴포넌트의 일부로 쓰이므로, **스프라이트 픽셀 1개가 화면 픽셀 1개에 대응해야** 하기 때문입니다.

### Render Mode

- **Simple** — 스프라이트가 테두리 값을 사용하지 않습니다.
- **Sliced** — 테두리 값을 사용해 [9-슬라이싱](/user-manual/2D/slicing) 렌더링을 **늘리기** 방식으로 수행합니다.
- **Tiled** — 테두리 값을 사용해 [9-슬라이싱](/user-manual/2D/slicing) 렌더링을 **타일링** 방식으로 수행합니다.

:::tip 9-슬라이싱이란

버튼 배경처럼 **크기가 자주 바뀌는 UI 이미지**를 위한 기법입니다. 이미지를 아홉 조각으로 나눠, 모서리는 그대로 두고 가운데와 변만 늘리거나 반복해서 채웁니다. 그래서 버튼을 길게 늘여도 모서리가 찌그러지지 않습니다.

:::

### Texture Atlas

스프라이트가 참조하는 텍스처 아틀라스 에셋입니다.
