---
title: 재질 (Material)
---

3D 모델의 모든 표면은 **재질**을 사용해 그려집니다. 재질은 그 표면의 색상, 광택, 거칠기 같은 속성을 정의합니다.

OasisW에서 재질은 이 모든 속성을 한데 모아 놓은 에셋 유형입니다. 기본적으로 **Physical 재질**을 나타내며, 부드러운 플라스틱부터 거친 나무, 긁힌 금속까지 다양한 표현을 만들 수 있는 속성들을 제공합니다. 기존 **Phong 재질** 유형도 함께 지원합니다.

## 재질 가져오기

3D 모델 파일(FBX 등)을 OasisW에 업로드하면 **재질이 자동으로 함께 가져와집니다.** 3D 모델링 도구에 있던 것과 같은 속성으로 만들어집니다. 임베디드 미디어를 포함해 업로드하면(FBX만 해당) 관련된 텍스처 맵도 자동으로 연결됩니다.

## 새 재질 생성

에디터에서 직접 새 재질을 만들 수 있습니다. 에셋 패널의 **+** 버튼을 누르고 **Material**을 선택하십시오.

![재질 생성](/img/user-manual/assets/materials/create-asset-menu.jpg)

새 재질 에셋이 만들어지고 화면 오른쪽에 재질 인스팩터가 열립니다.

## 재질 선택

재질을 편집하려면 먼저 선택해야 합니다. 선택하면 재질 인스팩터가 나타납니다.

- 에셋 패널에서 재질을 직접 선택합니다.
- 모델 인스팩터나 모델 컴포넌트에서도 선택할 수 있습니다.
- 보통은 **재질 미리보기 아이콘을 클릭**하면 재질 인스팩터로 이동합니다.

![모델 인스팩터](/img/user-manual/assets/materials/model-inspector-simple.jpg)

## 재질 할당 {#assigning-materials}

모델 에셋에서 어느 부분에 어떤 재질이 할당되는지 바꿀 수도 있고, 모델 컴포넌트를 가진 **특정 엔티티에만** 다른 재질을 지정할 수도 있습니다.

### 에셋 재질

에셋 재질을 클릭하면 모델 에셋이 선택됩니다. 에셋 패널에서 모델 에셋을 직접 골라도 됩니다. 모델 인스팩터는 모델의 **메시 목록과 각각에 할당된 재질**을 보여 줍니다. `X` 버튼으로 재질을 지우고, 빈 슬롯을 클릭해 새 재질을 할당할 수 있습니다. 에셋 패널에서 재질 에셋을 슬롯으로 끌어다 놓아도 됩니다.

### 엔티티 재질

엔티티 재질을 클릭하면 먼저 **재질을 바꿀 메시 인스턴스를 고르라고 안내**합니다. 메시 인스턴스를 고르면 모델 컴포넌트에 새 재질 선택기가 나타나고, 그 엔티티에 대해서만 다른 재질을 지정할 수 있습니다.

![엔티티별 재질 지정](/img/user-manual/assets/materials/overridden.png)

## 재질 편집

재질을 선택하면 속성을 편집할 수 있습니다.

![재질 인스팩터](/img/user-manual/assets/materials/material-inspector.jpg)

## 재질 맵

재질 편집의 대부분은 여러 **슬롯에 텍스처 맵을 만들어 넣는 일**입니다. 재질의 텍스처 맵 슬롯에는 공통으로 다음 옵션들이 있습니다.

### 텍스처 에셋

첫 번째는 텍스처 에셋입니다. 이미지를 OasisW에 업로드하면 [텍스처 에셋](/user-manual/assets/types/texture)이 만들어지고, 이를 재질의 슬롯에 할당할 수 있습니다.

### 색상 또는 틴트 색상

일부 맵 슬롯은 텍스처 대신 **단색**을 쓸 수 있습니다. 텍스처가 할당된 경우 **틴트 색상**을 함께 지원하는 슬롯도 있습니다. 틴트를 켜면 그 색상이 텍스처 맵의 색상과 곱해집니다.

### 채널

일부 맵은 `0.0`부터 `1.0`까지의 **그레이스케일 값 하나만** 필요합니다. 이 경우 텍스처의 어느 채널을 쓸지 고를 수 있습니다. **RGB**는 세 채널을 모두 쓴다는 뜻이고, **R** · **G** · **B**는 각각 빨강 · 초록 · 파랑 채널만 쓴다는 뜻입니다.

### 텍스처 변환

| 속성 | 설명 |
|------|------|
| Apply to all Maps | 개별 맵에 오프셋과 타일링 값을 적용하려면 이 옵션을 해제하십시오. |
| Offset | 이 재질의 맵이 참조하는 첫 번째 UV 채널에 적용할 U와 V의 오프셋입니다. |
| Tiling | 이 재질의 맵이 참조하는 첫 번째 UV 채널에 적용할 U와 V의 스케일입니다. |
| Rotation | 이 재질의 맵이 참조하는 첫 번째 UV 채널에 적용할 U와 V의 회전입니다. |

### 앰비언트

앰비언트 속성은 재질이 **주변광 아래에서 어떻게 보이는지**를 결정합니다.

| 속성 | 설명 |
|------|------|
| AO Texture | 사전 베이킹된 앰비언트 오클루전을 담은 맵입니다. |
| Vertex Color | AO에 메시 버텍스 색상을 사용합니다. aoMap이 설정된 경우 버텍스 색상과 곱해집니다. |
| Color | 씬의 전역 앰비언트 색상과 곱할 틴트 색상입니다. |
| Intensity | 앰비언트 오클루전 강도입니다. 기본값은 1입니다. |

### 디퓨즈

디퓨즈 속성은 재질이 씬의 **동적 조명에서 나오는 확산광을 어떻게 반사하는지**를 정의합니다. 쉽게 말해 물체의 기본 색입니다.

| 속성 | 설명 |
|------|------|
| Texture | 픽셀마다 디퓨즈 색상을 지정하는 맵입니다. 설정하지 않으면 아래의 디퓨즈 색상이 대신 쓰입니다. |
| Vertex Color | 메시 버텍스 색상을 디퓨즈에 곱합니다. |
| Color | 디퓨즈 맵이 없으면 이것이 재질의 디퓨즈 색상입니다. 맵이 있고 틴트가 켜져 있으면 이 색상이 맵을 변조합니다. |

### 스펙큘러

스펙큘러 속성은 **반짝이는 하이라이트의 색**, 즉 광택을 정의합니다.

| 속성 | 설명 |
|------|------|
| Use Metalness | 스펙큘러 워크플로우와 메탈니스 워크플로우를 전환합니다. |
| Specular Map | 픽셀마다 스펙큘러 색상을 지정하는 맵입니다. 없으면 스펙큘러 색상이 쓰입니다. |
| Vertex Color | 스펙큘러에 메시 버텍스 색상을 사용합니다. |
| Color | 스펙큘러 맵이 없으면 이것이 재질의 스펙큘러 색상입니다. |
| Metalness Map | [메탈니스 사용 시] 픽셀마다 메탈니스 값을 지정합니다. 1은 금속, 0은 비금속입니다. |
| Metalness | 표면이 얼마나 금속적인지 정의합니다. 0(유전체)에서 1(금속)까지입니다. |
| Metalness Specular Color | 메탈니스가 켜져 있을 때 스펙큘러 맵으로 반사에 색 틴트를 적용합니다. |
| Gloss Map | 픽셀마다 광택 값을 지정하는 글로스 맵입니다. 광택 속성에 의해 변조됩니다. |
| Glossiness | 표면의 매끄러움을 결정합니다. 값이 작으면 거칠고 하이라이트가 넓게 퍼지며, 값이 크면 매끄럽고 하이라이트가 좁게 모입니다. |
| Invert | 글로스 값을 반전시켜 거칠기처럼 다룹니다. 기본값은 꺼짐입니다. |

### 이미시브

이미시브 속성은 재질이 **스스로 빛을 내는 정도**를 조절합니다. 빛을 반사하는 것과는 반대 개념입니다.

| 속성 | 설명 |
|------|------|
| Texture | 픽셀마다 이미시브 색상을 지정하는 맵입니다. |
| Vertex Color | 이미시브에 메시 버텍스 색상을 사용합니다. |
| Color | 이미시브 맵이 없으면 이것이 재질의 이미시브 색상입니다. |
| Intensity | 이미시브 색상의 배수입니다. 아주 밝은 재질에 과밝기 효과를 낼 수 있습니다. |

### 불투명도

불투명도는 **투명도 수준**을 설정합니다.

| 속성 | 설명 |
|------|------|
| Blend Type | 이 재질의 블렌드 모드입니다. |
| Texture | 픽셀마다 불투명도를 지정하는 맵입니다. Amount 속성에 의해 변조됩니다. |
| Vertex Color | 불투명도에 메시 버텍스 색상을 사용합니다. |
| Alpha To Coverage | 알파 투 커버리지를 켜거나 끕니다. WebGL2에서만 동작합니다. |
| Opacity Dither | 불투명도를 디더링해 알파 블렌딩 없이 투명 효과를 냅니다. |
| Opacity Shadow Dither | 그림자 불투명도를 디더링해 알파 블렌딩 없이 투명 그림자를 냅니다. |

### 노멀

노멀 맵을 지정합니다. 표면의 요철을 표현하는 맵으로, **OasisW에서는 높이 맵이 아닌 노멀 맵을 써야 합니다.**

| 속성 | 설명 |
|------|------|
| Texture | 픽셀마다 표면 노멀을 지정하는 노멀 맵입니다. Bumpiness 속성에 의해 변조됩니다. |

### 패럴랙스

패럴랙스 맵은 표면에 **깊이의 착시**를 더해 노멀 맵을 더 사실적으로 만듭니다. 재질에 노멀 맵을 설정한 경우에만 활성화됩니다.

| 속성 | 설명 |
|------|------|
| Height Map | 패럴랙스 효과의 픽셀당 강도를 지정하는 높이 맵입니다. 흰색이 최대 높이, 검은색이 높이 0입니다. |

### 클리어코트

클리어코트는 표면 위에 **얇고 투명한 코팅층**을 흉내 냅니다. 자동차 페인트나 플라스틱 표면을 표현할 때 씁니다.

| 속성 | 설명 |
|------|------|
| Clear Coat Factor | 0부터 1까지 클리어코트 레이어의 강도를 정의합니다. |

### 광휘

광휘는 직물이나 벨벳 같은 **섬유 재질에서 보이는 부드러운 반사**를 흉내 냅니다. 표면의 미세한 거칠기가 만들어 내는 산란 반사를 표현합니다.

| 속성 | 설명 |
|------|------|
| Use Sheen | 광휘 스펙큘러 효과를 켭니다. |
| Invert | 광휘 광택을 반전시켜 거칠기처럼 다룹니다. |

### 굴절

굴절은 빛이 투명한 물질을 지나며 **방향이 꺾이는 현상**을 흉내 냅니다. 유리, 물, 크리스털을 표현할 때 씁니다.

| 속성 | 설명 |
|------|------|
| Dynamic Refractions | 굴절을 위한 그랩 패스를 사용합니다. |
| Refraction Map | 픽셀마다 굴절량을 정의하는 맵입니다. |
| Vertex Color | 굴절 강도에 버텍스 색상을 사용하거나 굴절 맵과 곱합니다. |
| Refraction | 재질을 통과하는 빛의 비율을 결정합니다. |
| Index Of Refraction | 재질을 통과하는 빛의 왜곡 정도를 결정합니다. 1.0 / 굴절률로 표현됩니다. |
| Dispersion | 볼륨을 통과하는 색상의 각도 분리(색수차) 강도입니다. 기본값은 0이며 분산이 없음을 뜻합니다. |

### 무지개 빛

무지개 빛은 **보는 각도에 따라 색이 변하는 현상**을 흉내 냅니다. 비누방울, 기름막, 나비 날개, 진주 같은 재질을 표현합니다.

| 속성 | 설명 |
|------|------|
| Use Iridescence | 무지개 빛 회절 효과를 켭니다. |

### 환경

환경 속성은 재질이 **주변 환경을 어떻게 반사하는지**를 결정합니다.

| 속성 | 설명 |
|------|------|
| Sphere Map | 환경 반사를 근사하는 스피어 맵 텍스처입니다. 설정하면 큐브 맵 속성이 숨겨집니다. 두 속성은 함께 쓸 수 없습니다. |
| Cube Map | 환경 반사를 근사하는 [큐브 맵](/user-manual/assets/types/cubemap) 텍스처입니다. 스피어 맵보다 정확합니다. 설정하면 스피어 맵 속성이 숨겨집니다. |
| Reflectivity | 재질에서 얼마나 많은 빛이 반사되는지 결정합니다. 기본값은 1(완전 반사)입니다. |

### 라이트 맵

라이트 맵은 **미리 계산해 구워 둔 확산 조명**을 담고 있습니다. 실행 중 동적 조명 계산을 미리 처리해 두는 것이므로 최적화 수단으로 봅니다.

| 속성 | 설명 |
|------|------|
| Texture | 사전 베이킹된 확산 조명을 담은 라이트맵 텍스처입니다. 라이트맵을 쓰려면 메시에 UV 세트가 두 개 있어야 하며, 라이트맵은 두 번째 UV 세트를 사용합니다. |
| Vertex Color | 구워 둔 버텍스 조명을 사용합니다. lightMap이 설정된 경우 버텍스 색상과 곱해집니다. |

### 기타 렌더 상태

지정한 재질로 메시를 그릴 때의 추가 동작을 조절합니다.

| 속성 | 설명 |
|------|------|
| Depth Test | 켜면 픽셀마다 깊이 테스트를 수행해, 앞을 가리는 것이 없을 때만 메시가 보입니다. 끄면 깊이 버퍼와 상관없이 항상 그려집니다. 기본값은 켜짐입니다. |
| Depth Write | 켜면 이 메시의 깊이 정보를 깊이 버퍼에 기록합니다. 뒤에 그려지는 메시가 이 메시를 상대로 깊이 테스트를 할 수 있게 됩니다. 기본값은 켜짐입니다. |
| Cull | None은 앞뒤 양면을 모두 그립니다. Front Faces는 앞면만, Back Faces는 뒷면만 그리며 이것이 기본값입니다. OasisW는 반시계 방향 버텍스 와인딩을 앞면으로 봅니다. 뒷면 컬링은 성능에 유리합니다. |
| Use Fog | 씬 설정에 정의된 안개를 적용합니다. |
| Use Lighting | 조명을 적용합니다. |
| Use Skybox | 사전 필터링된 환경 맵으로 씬 스카이박스를 적용합니다. |
| Use Tonemap | 톤매핑을 적용합니다. 기본값은 켜짐입니다. |

:::tip 처음 만질 때는

속성이 많아 보이지만, 처음에는 **디퓨즈의 Color와 Texture**, 그리고 **스펙큘러의 Glossiness** 세 가지만 만져도 대부분의 표현이 됩니다. 나머지는 필요해질 때 하나씩 열어 보십시오.

:::
