---
title: 애니메이션 (Animation)
---

애니메이션 에셋은 3D 모델에서 **하나의 애니메이션**을 재생하는 데 사용됩니다. 애니메이션 데이터가 들어 있는 3D 씬 파일(FBX, GLB 등)을 업로드하면 가져올 수 있습니다. 파일 안의 애니메이션 데이터는 에셋 파이프라인이 뽑아내고, 게임에서 실제로 쓰이는 [Target 에셋](/user-manual/assets)이 만들어집니다.

:::note 이렇게 이해하시면 됩니다

모델 파일 하나에 '걷기', '뛰기', '점프' 애니메이션이 들어 있다면, 업로드 후 애니메이션 에셋이 **세 개** 만들어집니다. 하나의 에셋이 하나의 동작을 담당합니다.

:::

## 가져오기

1. 애니메이션이 포함된 모델 파일을 에셋 패널로 끌어다 놓거나, **+ › Upload Files**로 올립니다.
2. 변환이 끝나면 `Animation` 유형의 에셋이 목록에 나타납니다.
3. 타입 필터에서 `Animation`을 골라 보면 애니메이션만 추려서 볼 수 있습니다.

가져오기 소스는 `.glb` · `.fbx`이고, 결과 리소스 확장자는 `.glb`입니다.

## 애니메이션 미리보기

인스팩터에는 **템플릿이나 모델 에셋과 함께 애니메이션을 미리 볼 수 있는 뷰어**가 들어 있습니다. 여러 캐릭터 리그에 두루 쓸 수 있는 애니메이션 하나를 가지고 있을 때 특히 유용합니다. 어떤 캐릭터에 붙였을 때 자연스러운지 씬에 배치하기 전에 확인할 수 있기 때문입니다.

![에셋 인스팩터의 애니메이션 미리보기](/img/user-manual/assets/animation/inspector-preview.gif)

[애니메이션 상태 그래프 에디터](/user-manual/animation/anim-state-graph-assets)에서 상태를 선택할 때에도 같은 뷰어가 나타납니다. 상태를 고르면 **그 그래프를 사용하는 씬의 모든 엔티티가 목록에 표시되어**, 어떤 엔티티로 미리 볼지 선택할 수 있습니다.

![애니메이션 상태 그래프의 미리보기](/img/user-manual/assets/animation/anim-state-graph-preview.gif)

## 어떻게 사용하나요

애니메이션 에셋 하나만으로는 재생되지 않습니다. 엔티티에 [Anim 컴포넌트](/user-manual/scenes/components/anim)를 추가하고, 상태 그래프에 이 애니메이션을 연결해야 합니다. 여러 동작을 상황에 따라 바꿔 가며 재생하려면 상태 그래프가 필요합니다.

:::warning 잘 안 될 때

애니메이션이 재생되지 않는다면 **모델의 뼈대(리그) 구조와 애니메이션의 뼈대 이름이 맞는지** 확인하십시오. 이름이 다르면 애니메이션은 로드되지만 아무 움직임도 나타나지 않습니다.

:::
