---
title: 스크립트 속성 (Script Attributes)
---

스크립트 속성은 스크립트에서 밖으로 열어 둘 설정값들을 정의하는 OasisW의 강력한 기능입니다. 즉, 스크립트를 어떻게 동작시킬지 조절하는 값들을 겉으로 노출해 두는 것입니다. 코드에서 스크립트를 만들거나 설정할 때 이 값들을 프로그램으로 쉽게 바꿀 수 있습니다. 덕분에 스크립트를 한 번만 작성해 두면, 인스턴스마다 또는 다른 팀원이 그 동작과 값을 손쉽게 조절할 수 있습니다.

## 스크립트 속성을 사용하는 이유

* **명확한 공개 인터페이스:** 속성은 스크립트에서 어떤 부분이 사용자가 바꾸라고 열어 둔 것인지를 분명하게 정해 줍니다. 그래서 코드가 더 읽기 쉽고 관리하기 좋아집니다.
* **시각적 구성:** 시각적 개발 도구에서는 속성이 편집 가능한 입력 칸으로 나타날 수 있습니다. 그래서 아티스트, 디자이너, 다른 개발자가 코드를 깊이 들여다보지 않고도 스크립트를 손쉽게 설정할 수 있습니다.
* **프로그래밍 방식 구성:** 코드로 엔티티와 스크립트 컴포넌트를 만들거나 관리할 때, 이 속성들의 초기값을 코드에서 바로 정할 수 있어 상황에 맞게 유연하게 설정할 수 있습니다.
* **재사용성:** "Movement" 같은 범용 스크립트를 하나 만들어 두고, 코드에서 속성(속도, 방향, 대상 등)만 바꿔 여러 엔티티에 맞게 재사용할 수 있습니다.
* **협업:** 코딩을 주로 하지 않는 팀원도 게임플레이 요소, 캐릭터 스탯, 시각적 값을 직접 수정할 수 있게 해 줍니다.
* **빠른 반복:** 코드에서 초기값만 바꿔 가며 여러 설정과 값을 빠르게 시험해 볼 수 있습니다.

## 작동 방식

스크립트에서 속성을 선언한다는 것은, 초기값을 정하고 이후에 바꿀 수 있는 값을 만들어 두는 것입니다.

* **코드에서:** 스크립트를 스크립트 컴포넌트에 추가할 때, 또는 실행 중에 스크립트 인스턴스의 속성을 통해 이 값들을 설정할 수 있습니다.
* **프로그래밍 방식 접근:** 스크립트 인스턴스를 통해 속성 값을 직접 읽고 바꿀 수 있습니다.

예를 들어 회전 스크립트에 `speed` 속성을 열어 둘 수 있습니다. 코드에서 `initialize` 메서드 안에 `this.speed = 5;`처럼 설정하거나, 엔티티를 준비할 때 `entity.script.myScript.speed = 5;`처럼 설정할 수 있습니다. 이렇게 하면 똑같은 스크립트 로직을 쓰면서도 회전 객체마다 서로 다른 회전 속도를 줄 수 있습니다.
