---
title: 스프라이트 (Sprite)
---

스프라이트 컴포넌트는 [스프라이트 에셋][1]을 씬에 그려서 보여주고 움직이게(애니메이션) 합니다.

스프라이트에는 단순(Simple)과 애니메이션(Animated) 두 종류가 있습니다.

## 단순 스프라이트

단순 스프라이트 컴포넌트는 아틀라스에서 한 장의 프레임만 골라 보여줍니다

![Simple Sprite](/img/user-manual/scenes/components/component-sprite-simple.png)

## 단순 스프라이트 컴포넌트 속성

| 속성    | 설명 |
|-------------|-------------|
| Type        | Simple 또는 Animated 중 하나입니다. |
| Sprite      | 화면에 보여줄 스프라이트 에셋입니다. |
| Frame       | 스프라이트에서 보여줄 프레임의 번호(인덱스)입니다. |
| Color       | 스프라이트에 색조(틴트)로 입힐 색상입니다. |
| Opacity     | 스프라이트가 얼마나 투명한지 정합니다. |
| Flip X      | 그려진 스프라이트를 좌우로 뒤집습니다. |
| Flip Y      | 그려진 스프라이트를 위아래로 뒤집습니다. |
| Layers      | 스프라이트를 그릴 레이어입니다. |
| Draw Order  | 이 스프라이트가 그려지는 순서입니다. 숫자가 작을수록 먼저 그려집니다. |

## 애니메이션 스프라이트

애니메이션 스프라이트 컴포넌트에는 여러 개의 스프라이트 애니메이션 클립이 연결되어 있어, 서로 다른 스프라이트 에셋을 번갈아 재생할 수 있습니다.

![Animated Sprite](/img/user-manual/scenes/components/component-sprite-animated.png)

## 애니메이션 스프라이트 컴포넌트 속성

| 속성   | 설명 |
|------------|-------------|
| Type       | Simple 또는 Animated 중 하나입니다. |
| Frame      | 스프라이트에서 보여줄 프레임의 번호(인덱스)입니다. |
| Color      | 스프라이트에 색조(틴트)로 입힐 색상입니다. |
| Opacity    | 스프라이트가 얼마나 투명한지 정합니다. |
| Flip X     | 그려진 스프라이트를 좌우로 뒤집습니다. |
| Flip Y     | 그려진 스프라이트를 위아래로 뒤집습니다. |
| Speed      | 이 스프라이트 컴포넌트에 연결된 스프라이트 애니메이션 클립이 재생되는 속도에 곱해지는 배수입니다. |
| Layers     | 스프라이트를 그릴 레이어입니다. |
| Draw Order | 이 스프라이트가 그려지는 순서입니다. 숫자가 작을수록 먼저 그려집니다. |
| Auto Play  | 스프라이트가 켜질 때 자동으로 재생할 스프라이트 애니메이션 클립의 이름입니다. |

## 스프라이트 애니메이션 클립 속성

| 속성 | 설명 |
|----------|-------------|
| Name     | 스프라이트 애니메이션 클립의 이름입니다. 개별 클립을 가리킬 때 사용합니다. |
| Loop     | true이면 애니메이션 클립이 끝에 도달했을 때 다시 처음으로 돌아가 반복됩니다. |
| FPS      | 클립이 재생되는 속도로, 초당 프레임 수를 뜻합니다. |
| Sprite   | 이 클립을 재생하는 데 사용하는 스프라이트 에셋입니다. |

## 스크립팅 인터페이스
