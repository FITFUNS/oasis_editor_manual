---
title: 파티클 시스템 (Particle System)
---

파티클 시스템 컴포넌트는 3D 공간에서 파티클을 뿜어내는 방출기를 만들어 줍니다.

컴포넌트 패널 오른쪽 위에 있는 토글로 이 컴포넌트를 켜거나 끌 수 있습니다. 켜면 파티클 시스템이 씬에 추가되어 화면에 그려집니다.

![Particle System component](/img/user-manual/scenes/components/component-particle-system.png)

## 속성

| Property        | Description |
|-----------------|-------------|
| Auto Play       | 체크하면 파티클 시스템이 만들어지자마자 바로 재생됩니다. 체크하지 않으면 스크립트에서 파티클 시스템 컴포넌트의 play 함수를 직접 불러 줘야 재생됩니다. |
| Particle Count  | 이 파티클 시스템이 한 번에 다룰 수 있는 파티클의 최대 개수입니다. |
| Lifetime        | 파티클이 생겨나서 사라질 때까지의 시간(초)입니다. |
| Emission Rate   | 파티클을 뿜는 간격 범위의 아래쪽 값입니다. 다음 파티클을 뿜는 시점은 'Emission Rate'와 'Emission Rate 2' 사이에서 무작위로 정해집니다. |
| Emission Rate2  | 파티클을 뿜는 간격 범위의 위쪽 값입니다. 다음 파티클을 뿜는 시점은 'Emission Rate'와 'Emission Rate 2' 사이에서 무작위로 정해집니다. |
| Start Angle     | 파티클이 처음 생길 때의 회전 각도(도) 범위의 아래쪽 값입니다. 각 파티클마다 이 각도는 'Start Angle'과 'Start Angle 2' 사이에서 무작위로 정해집니다. |
| Start Angle2    | 파티클이 처음 생길 때의 회전 각도(도) 범위의 위쪽 값입니다. 각 파티클마다 이 각도는 'Start Angle'과 'Start Angle 2' 사이에서 무작위로 정해집니다. |
| Loop            | 체크하면 파티클 시스템이 끝없이 파티클을 뿜습니다. 체크하지 않으면 'Particle Count'에 정한 개수만큼 뿜은 뒤 멈춥니다. |
| Pre Warm        | 켜면 파티클 시스템이 이미 한 바퀴를 다 돈 상태에서 시작합니다. 이 옵션은 반복(Loop) 파티클 시스템에서만 쓸 수 있습니다. |
| Lighting        | 체크하면 파티클이 씬의 방향성 조명과 환경 조명의 영향을 받습니다. 경우에 따라 더 사실적으로 보이도록 파티클 시스템에 노멀 맵을 함께 지정하는 것이 좋습니다. |
| Half-Lambert    | 하프 람버트 조명을 켜면 빛이 파티클 뒤쪽에서 비출 때 파티클이 지나치게 평평해 보이는 것을 막아 줍니다. 물리적으로 정확한 방식은 아니지만 보기에 더 나은 결과를 낼 수 있습니다. 이 옵션은 Lighting이 켜져 있을 때만 쓸 수 있습니다. |
| Intensity | 파티클 색상의 밝기를 원하는 만큼 키우거나 줄일 수 있게 해 줍니다. |
| Depth Write      | 체크하면 파티클이 깊이 버퍼에 깊이 정보를 씁니다. 체크하지 않으면 깊이 버퍼는 그대로 두고, 파티클끼리는 그려지는 순서대로 서로 덮어씁니다. |
| Depth Softening | 이 값은 파티클이 다른 표면에 가까워질 때 얼마나 서서히 사라지는지를 정합니다. 파티클이 표면을 뚫고 잘려 보이는 현상을 막아 줍니다. 값을 0으로 두면 깊이 소프트닝이 꺼집니다. 0보다 크게 두면 깊이 비교를 위해 씬을 깊이 타겟에 한 번 더 그려야 하는데, 이는 매 프레임 드로우 콜 수를 늘려 성능에 꽤 큰 영향을 줄 수 있습니다. |
| Sorting Mode    | 정렬 모드는 파티클을 그리는 순서를 정합니다. 고를 수 있는 옵션은 다음과 같습니다: <ul><li>None: 파티클을 아무 순서로나 그립니다. 이 옵션을 고르면 (하드웨어가 부동소수점 텍스처를 지원할 때) 파티클 시스템이 GPU에서 계산됩니다. 성능이 가장 좋으므로 이 설정을 권장합니다.</li><li>Camera Distance: 파티클을 CPU에서 정렬해 카메라의 z 깊이 기준으로 먼 것부터 가까운 것 순으로 그립니다.</li><li>Newer First: 파티클을 CPU에서 정렬해 나이순으로 그리되, 가장 어린 것부터 그립니다.</li><li>Older First: 파티클을 CPU에서 정렬해 나이순으로 그리되, 가장 오래된 것부터 그립니다.</li></ul> |
| Blending Mode   | 블렌딩 모드는 파티클이 프레임 버퍼에 그려질 때 기존 색과 어떻게 섞이는지를 정합니다. Prgb를 파티클 픽셀의 RGB 색, Pa를 그 알파 값, Drgb를 이미 프레임 버퍼에 있던 RGB 색이라고 해 봅시다. 고를 수 있는 옵션은 다음과 같습니다: <ul><li>Additive: Prgb + Drgb</li><li>Alpha: Prgb x Pa + Drgb x (1 - Pa)</li><li>Multiply: Prgb * Drgb</li></ul> |
| Stretch         | 파티클이 속도에 따라 얼마나 길게 늘어나는지를 정하는 월드 단위 값입니다. 파티클은 중심에서 이전 위치 쪽으로 늘어납니다. |
| Align To Motion | 파티클을 움직이는 방향에 맞춰 정렬합니다. |
| Emitter Shape   | 방출기의 모양입니다. |
| Emitter Extents | 파티클이 무작위로 생겨나는 로컬 공간 경계 상자의 절반 크기입니다. |
| Inner Extents   | 파티클이 생겨나지 않는, 로컬 공간 경계 상자 안의 제외 영역입니다. |
| Emitter Radius  | 파티클이 무작위로 생겨나는 범위의 반지름입니다. |
| Inner Radius    | 파티클이 생겨나지 않는 안쪽 구의 반지름입니다. |
| Wrap            | 래핑(경계에서 반대편으로 넘어가기) 경계를 켭니다. |
| Local Space     | 파티클을 방출기 노드의 변환에 묶어 함께 움직이게 합니다. |
| Screen Space    | 파티클을 2D 스크린 공간에 그립니다. 파티클 시스템이 루트에 ScreenComponent가 있는 계층 구조 안에 있을 때 설정해야 하며, 이렇게 하면 파티클 시스템이 ElementComponent의 렌더링과 어울리게 됩니다. |
| Layers          | 이 파티클 시스템이 속한 레이어입니다. 여러 레이어에 속하면 그만큼 여러 번 그려집니다. |
| Wrap Bounds     | 소유자 엔티티의 위치를 중심으로 한 월드 공간 AABB 영역입니다. 파티클이 이 영역의 한쪽 경계를 넘으면 반대편으로 순간이동합니다. 래핑을 쓰는 방출기의 소유자 엔티티를 움직이면 비 같은 환경 효과를 만들 수 있습니다. |
| Orientation     | 방향 모드는 파티클 평면이 어느 쪽을 향할지 정합니다. 고를 수 있는 옵션은 다음과 같습니다: <ul><li>Screen: 파티클이 항상 카메라를 바라봅니다. </li><li>World Normal: 사용자가 월드 공간 노멀을 정해 평면의 방향을 지정합니다. </li><li>Emitter Normal: 위와 비슷하지만, 노멀이 방출기(엔티티) 변환의 영향을 받습니다.</li></ul>  |
| Particle Normal | 파티클 평면의 방향을 정하는 월드 또는 방출기 공간 벡터입니다. |
| Color Map       | 시스템의 모든 파티클에 입힐 컬러 맵 텍스처입니다. 텍스처 에셋을 지정하지 않으면 기본 스팟 텍스처가 쓰입니다. |
| Normal Map      | 시스템의 모든 파티클에 입힐 노멀 맵 텍스처입니다. 노멀 맵을 입히면 빌보드 파티클이 씬의 조명과 더 자연스럽게 어울려 보입니다. |
| Model Asset     | 모델 에셋입니다. 이 모델에서 찾은 첫 번째 메시가 평면 빌보드 대신 모든 파티클의 모양으로 쓰입니다. |
| Render Asset    | 메시로 된 파티클을 그릴 때 모델 에셋 대신 쓸 수 있는 렌더 에셋입니다. |
| Local Velocity  | 파티클 시스템의 로컬 좌표계를 기준으로, 각 파티클의 속도가 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. 곡선 편집기에서 곡선을 두 개 지정하면 로컬 속도는 두 곡선 사이에서 무작위로 정해집니다. |
| Velocity        | 월드 좌표계를 기준으로, 각 파티클의 속도가 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. 곡선 편집기에서 곡선을 두 개 지정하면 속도는 두 곡선 사이에서 무작위로 정해집니다. |
| Radial Speed  | 파티클의 방사 속도가 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. 파티클마다 방사 방향은 방출기 원점에서 그 파티클의 현재 위치를 향합니다. 곡선 편집기에서 곡선을 두 개 지정하면 값은 두 곡선 사이에서 무작위로 정해집니다. |
| Rotation Speed  | 각 파티클의 회전 속도가 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. 곡선 편집기에서 곡선을 두 개 지정하면 회전 속도는 두 곡선 사이에서 무작위로 정해집니다. |
| Scale           | 각 파티클의 크기가 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. 기본적으로 파티클은 가로세로 1 단위 크기입니다. 곡선 편집기에서 곡선을 두 개 지정하면 크기는 두 곡선 사이에서 무작위로 정해집니다. |
| Color           | 각 파티클의 색이 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. |
| Opacity         | 각 파티클의 불투명도가 시간에 따라 어떻게 바뀌는지를 나타내는 곡선입니다. 곡선 편집기에서 곡선을 두 개 지정하면 불투명도는 두 곡선 사이에서 무작위로 정해집니다. |

## 스크립팅 인터페이스

[스크립트 컴포넌트][2]를 이용하면 코드로 파티클 시스템 컴포넌트의 속성을 바꿀 수 있습니다. 파티클 시스템 컴포넌트의 스크립팅 인터페이스는 [여기][3]에서 볼 수 있습니다.
