---
title: 애님 (Anim)
---

애님 컴포넌트는 애님 상태 그래프 에셋과 거기에 필요한 애니메이션 에셋들을 하나의 엔티티에 함께 연결해 주는 역할을 합니다.

아래 그림은 엔티티에 막 추가한 애님 컴포넌트의 모습입니다. 애님 상태 그래프 에셋을 골라 넣을 수 있는 빈 슬롯이 하나 보입니다.

![New Anim Component](/img/user-manual/anim/new_anim_component.png)

애님 상태 그래프 에셋을 골라 넣으면, 애님 컴포넌트에 애니메이션 에셋을 넣을 슬롯 목록이 나타납니다. 상태 그래프에 들어 있는 모든 레이어의 애니메이션 상태마다 슬롯이 하나씩 생깁니다. 바로 여기에 실제 애니메이션 데이터를 넣어, 앞서 만들어 둔 상태 그래프에 연결하는 것입니다. 여러 애님 컴포넌트가 같은 애님 상태 그래프 에셋을 함께 쓸 수 있으며, 이때 각 컴포넌트는 저마다 다른 애니메이션 에셋을 넣어 둘 수 있습니다.

![Anim Component With Graph](/img/user-manual/anim/anim_component_with_graph.png)

애니메이션 상태 슬롯을 모두 채우면 이제 애니메이션을 재생할 수 있습니다. 재생하는 방법은 두 가지입니다. 스크립트에서 `entity.anim.playing = true`를 호출해 재생하거나, `Activate` 옵션을 켜 두면 OasisW 프로젝트가 시작될 때 자동으로 재생됩니다.

애님 컴포넌트에는 애니메이션 재생 속도를 조절하는 옵션도 있습니다. 이 속도는 상태 그래프 안의 모든 애니메이션에 함께 적용됩니다.
