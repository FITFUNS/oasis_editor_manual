스크립트 컴포넌트를 사용하면 엔티티가 여러분이 직접 만든 스크립트를 실행할 수 있습니다. 즉, 엔티티가 처음 만들어질 때 실행되고 이후 매 프레임마다 새로 갱신되는 코드를 JavaScript 언어로 작성할 수 있습니다.

스크립트 컴포넌트는 컴포넌트 패널의 오른쪽 위에 있는 토글로 켜거나 끌 수 있습니다. 켜져 있으면 이 컴포넌트에 연결된 모든 스크립트의 업데이트 함수가 프레임마다 한 번씩 호출됩니다.

![Script component](/img/user-manual/scenes/components/component-script.png)

새 스크립트를 만들려면 에셋 패널의 **`+`** 버튼을 누른 뒤 새 스크립트를 선택하세요. 그러면 팝업이 뜨는데, 여기에 스크립트 이름을 입력하고 Enter를 누르면 됩니다.

<img loading="lazy" src="/img/user-manual/scenes/components/new-script.jpg" />

이렇게 만든 새 스크립트는 스크립트 컴포넌트 위로 드래그해서 넣을 수 있습니다. 또는 스크립트 컴포넌트 인스펙터에서 스크립트 추가 버튼을 누른 다음 에셋 패널에서 원하는 스크립트를 골라도 됩니다.

스크립트를 편집하고 싶다면 OasisW 코드 에디터를 사용합니다. 링크로 표시된 스크립트 이름을 클릭하거나, 에셋 패널에서 스크립트를 고른 뒤 편집을 누르면 에디터가 열립니다.
