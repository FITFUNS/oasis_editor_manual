---
title: 사운드 (Sound)
---

사운드 컴포넌트는 오디오 샘플을 언제 어떻게 재생할지 관리합니다.

![Sound component](/img/user-manual/scenes/components/component-sound.png)

각 사운드 컴포넌트에는 소리를 재생하는 "슬롯"이 들어 있습니다. 슬롯마다 서로 다른 오디오 에셋을 넣을 수 있고, 각 슬롯은 다른 슬롯과 상관없이 따로 재생됩니다.

새 슬롯을 추가하려면 "ADD SLOT" 버튼을 누르세요. 슬롯을 지우려면 각 슬롯 머리말에 있는 휴지통 아이콘을 누르면 됩니다.

사운드 컴포넌트는 컴포넌트 패널의 오른쪽 위에 있는 토글로 켜거나 끌 수 있습니다. 켜져 있으면 자동 재생으로 표시된 슬롯이 저절로 재생됩니다. 나머지 슬롯은 스크립트로 재생할 수 있습니다.

## 컴포넌트 속성

| 속성        | 설명 |
|-----------------|-------------|
| Positional      | 켜면 오디오 에셋이 3D 공간에서 엔티티가 있는 위치에서 나는 것처럼 들립니다. |
| Volume          | 오디오를 재생할 때 각 슬롯의 볼륨에 곱해지는 전체 볼륨입니다. |
| Pitch           | 오디오를 재생할 때 각 슬롯의 피치에 곱해지는 전체 피치입니다. 값이 1이면 오디오가 원래 음높이 그대로 재생됩니다. |
| Ref Distance    | 소리를 듣는 위치(리스너)에서 소리가 멀어질 때 볼륨을 줄이기 시작하는 기준 거리입니다. |
| Max Distance    | 이 거리를 넘어가면 오디오 볼륨이 더 이상 줄어들지 않습니다. 이 거리에서 볼륨이 반드시 0이 되는 것은 아니고, 다만 그 이후로는 감쇠가 멈춥니다. |
| Distance Model  | 소리가 리스너에게서 멀어질 때 볼륨을 줄이는 계산 방식을 정합니다. Linear, Inverse, Exponential 중에서 고를 수 있습니다. |
| Roll-off Factor | 볼륨이 줄어드는 속도입니다. |

## 슬롯 속성

| 속성        | 설명 |
|-----------------|-------------|
| Name            | 슬롯의 이름입니다. 코드에서 이 슬롯을 가리킬 때 사용합니다. |
| Asset           | 재생할 오디오 에셋입니다. |
| Start Time      | 소리 재생을 시작할 지점(시간)입니다. |
| Duration        | Start Time부터 재생할 소리의 길이입니다. |
| Auto Play       | 켜면 로드될 때 슬롯이 저절로 재생됩니다. 끄면 스크립트로 직접 재생해야 합니다. |
| Overlap         | 켜면 이 슬롯은 이미 재생 중이던 소리를 멈추지 않고 겹쳐서 새 소리를 냅니다. 겹침은 짧은 소리를 여러 번 연달아 재생할 때 쓰면 좋습니다. 겹쳐서 재생된 소리는 엔티티가 사라져도 멈추지 않고, 소리가 끝나거나 스크립트로 직접 멈출 때만 멈춥니다. |
| Loop            | 켜면 슬롯이 끊김 없이 계속 반복 재생됩니다. 끄면 끝까지 한 번만 재생됩니다. |
| Volume          | 이 슬롯에서 재생되는 오디오 에셋의 볼륨입니다. |
| Pitch           | 오디오가 재생되는 음높이(피치)입니다. 값이 1이면 오디오가 원래 음높이 그대로 재생됩니다. |

## 스크립팅 인터페이스
