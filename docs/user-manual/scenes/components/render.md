---
title: 렌더 (Render)
---

렌더 컴포넌트를 붙이면 엔티티에 상자나 구 같은 기본 도형, 또는 준비해 둔 렌더 에셋을 화면에 그릴 수 있습니다.

컴포넌트 패널 오른쪽 위에 있는 토글로 이 컴포넌트를 켜거나 끌 수 있습니다. 켜면 컴포넌트가 가리키는 메시 인스턴스가 씬에 추가되어 화면에 그려집니다.

![Render component](/img/user-manual/scenes/components/component-render.png)

## 속성

| 속성              | 설명 |
|-----------------------|-------------|
| Type                  | 어떤 그래픽 객체를 그릴지 정하는 유형입니다. 다음 중 하나를 고를 수 있습니다: <ul><li>Asset</li><li>Box</li><li>Capsule</li><li>Cone</li><li>Cylinder</li><li>Plane</li><li>Sphere</li></ul> |
| Asset                 | 이 렌더 컴포넌트가 그릴 렌더 에셋입니다. Type이 'Asset'으로 되어 있을 때만 쓰입니다. 렌더 컴포넌트 하나에는 렌더 에셋을 딱 하나만 지정할 수 있습니다. |
| Cast Shadows          | 켜면 이 컴포넌트가 그리는 메시 인스턴스가 씬의 다른 메시 인스턴스 위에 그림자를 드리웁니다. |
| Cast Lightmap Shadows | 켜면 이 컴포넌트가 그리는 메시 인스턴스가 라이트맵에 그림자를 남깁니다. |
| Receive Shadows       | 켜면 이 컴포넌트가 그리는 메시 인스턴스가 씬의 다른 메시 인스턴스가 만든 그림자를 받아 표시합니다. |
| Static                | 이 렌더 컴포넌트를 쓰는 엔티티가 앞으로 전혀 움직이지 않는다면 이 상자를 체크하세요. 그러면 엔진이 성능을 높이는 최적화를 할 수 있습니다. |
| Lightmapped           | 켜면 이 컴포넌트의 메시 인스턴스가 실시간 조명의 영향을 받지 않고, 미리 구워 둔 라이트맵 조명만 받습니다. |
| Custom AABB           | 켜면 사용자가 직접 정한 경계 상자를 이 메시 인스턴스의 화면 표시 여부(컬링) 판단에 씁니다. 이는 뼈대가 움직이는 스킨드 캐릭터에서 유용한 최적화로, 넉넉하게 큰 경계 상자를 미리 지정해 두면 뼈 위치를 따라 매 프레임 경계 상자를 다시 계산하지 않아도 됩니다. |
| Batch Group           | 이 컴포넌트의 메시 인스턴스가 속한 배치 그룹입니다. |
| Layers                | 이 메시가 속할 레이어입니다. |
| Materials             | 이 컴포넌트의 메시 인스턴스를 그릴 때 쓸 재질 에셋입니다. 재질 하나가 메시 인스턴스 하나에 짝지어집니다. |
