---
title: 애님 컴포넌트 (Anim Component)
---

**애님(anim) 컴포넌트**는 앞서 만든 [애님 상태 그래프](/user-manual/animation/anim-state-graph-assets/)를 **엔티티에 실제로 붙여, 애니메이션을 재생시키는 부품**입니다. 엔티티에 이 컴포넌트를 추가하고 상태 그래프를 지정한 뒤, 그래프의 각 상태에 애니메이션 에셋을 채워 주면 애니메이션이 동작합니다.

![New Anim Component](/img/user-manual/anim/new_anim_component.png)

각 속성의 자세한 설명과 사용법은 [애님 컴포넌트 레퍼런스][1]에서 확인하십시오.

[1]: /user-manual/scenes/components/anim/
