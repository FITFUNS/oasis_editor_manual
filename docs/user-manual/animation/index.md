OasisW에는 캐릭터나 다른 모델을 움직이게 하는 **상태 기반 애니메이션 시스템**이 들어 있습니다. `.FBX`로 가져온 애니메이션 에셋을 **상태 머신** 방식으로 엮어 두면, 게임이 실행되는 동안 "언제 어떤 동작을 재생할지"를 손쉽게 제어할 수 있습니다.

## 전체 그림 먼저 잡기

애니메이션은 크게 **세 가지 조각**이 맞물려 돌아갑니다. 여기서는 이 조각들이 어떻게 이어지는지 큰 그림만 잡고, 각각의 자세한 내용은 이어지는 문서에서 다룹니다.

### OasisW의 애니메이션

먼저 모델을 움직일 **애니메이션 에셋**이 프로젝트에 있어야 합니다. 이게 실제 동작 데이터예요. 예를 들어 사람 캐릭터라면 `Idle`(가만히), `Walk`(걷기), `Jump`(점프) 같은 애니메이션을 가질 수 있습니다.

![Animations](/img/user-manual/anim/animations.gif)

이 낱개 동작들을 하나로 엮어 "이동 시스템"을 만드는 것이 **animstategraph(애님 상태 그래프) 에셋**입니다. 이걸 **엔티티의 동작을 정하는 상태 머신**이라고 생각하면 쉽습니다. 그래프의 각 "상태"가 하나의 애니메이션과 연결되므로, 상태들을 배치하면서 이렇게 정할 수 있습니다.

- 어떤 동작을 멈추고 다음 동작을 시작할 시점
- 두 동작이 바뀔 때 얼마나 부드럽게 이어질지(블렌딩)

마지막으로 **애님(anim) 컴포넌트**를 써서, 이 상태 그래프를 씬의 **특정 엔티티에 붙입니다.** 붙인 뒤 그래프의 각 상태에 실제 애니메이션 에셋을 하나씩 채워 주면, 모든 상태가 채워지는 순간 애님 컴포넌트가 **재생 가능한 상태**가 됩니다. 이때부터 정해 둔 애니메이션 동작이 OasisW 런처에서 실제로 움직입니다.

정리하면 **애니메이션 에셋(동작 데이터) → 상태 그래프(언제 무엇을 재생할지) → 애님 컴포넌트(엔티티에 붙이기)**, 이 순서로 완성됩니다.
