OasisW는 씬 안의 물체들을 정리하고 관리하기 위해 **엔티티 컴포넌트 시스템(ECS)**이라는 방식을 씁니다.

말은 어렵지만 개념은 단순합니다. **빈 상자에 필요한 부품을 골라 끼워서 물체를 만든다**고 생각하면 됩니다. 세 가지 용어만 알면 됩니다.

- [**엔티티(Entity)**](https://manual.oasisserver.link/engine/classes/Entity.html) — **빈 상자**입니다. 그 자체로는 아무 일도 하지 않고, 부품(컴포넌트)을 담는 그릇 역할만 합니다.
- [**컴포넌트(Component)**](https://manual.oasisserver.link/engine/classes/Component.html) — 상자에 끼우는 **부품**입니다. 카메라, 조명, 물리처럼 "이 물체가 무엇을 할 수 있는지"를 더해 줍니다.
- [**시스템(System)**](https://manual.oasisserver.link/engine/classes/ComponentSystem.html) — 같은 종류의 컴포넌트를 **한꺼번에 돌봐 주는 관리자**입니다. 우리가 직접 신경 쓸 일은 거의 없습니다.

예를 들어 "카메라"는 빈 엔티티에 **카메라 컴포넌트**를 끼운 것이고, "조명"은 빈 엔티티에 **조명 컴포넌트**를 끼운 것입니다. 이렇게 부품을 바꿔 끼우는 것만으로 다양한 물체를 만들 수 있습니다.

이 방식의 장점은 이렇습니다.

- **유연함** — 부품을 자유롭게 조합해 원하는 동작을 만들 수 있습니다.
- **깔끔함** — 각 기능이 자기 컴포넌트 안에 정리되어 있습니다.
- **성능** — 시스템이 같은 부품들을 묶어서 효율적으로 처리합니다.
